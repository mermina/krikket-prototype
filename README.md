# Krikket website prototype

Prototype of a new website for **Krikketsamband Íslands** (Icelandic Cricket Association), prepared for the board meeting on 18 Nov 2026 by Marina Ermina, built with AI assistance.

- `layout-a.html`: homepage layout A (photo slideshow, match centre)
- `layout-b.html`: homepage layout B (photo mosaic)
- `media/`: photos and logos

Match results, fixtures and event dates are examples, not real results. Photos and logos belong to Krikketsamband Íslands and its clubs.

Live:
- Layout A: https://mermina.github.io/krikket-prototype/layout-a.html
- Layout B: https://mermina.github.io/krikket-prototype/layout-b.html
